## 2. 必须补明的数学接口

### 2.1 归一化不能制造单位圆盘条件

正文只使用根的中心为零及总平方模为次数。未把 `a <= 1` 或全部原零点位于单位圆盘当作可用条件。零方差、重零点、`a=0` 分别在归约前处理；`a >= 5` 用 Lemma 7.1 解析排除。由此才可将有限检查区域限制为 `[0,5] × [0,1] × [0,1]`。

### 2.2 倒数矩中的权重必须逐项非负

Lemma 2.3 中加权 Cauchy–Schwarz 的权重为 `1-|q_j|^2`。它们的正性来自反例假设中的每一个临界点距离大于一，不来自单独的平均条件 `s<1`。引言据此明确说明：本文不证明平均倒数平方距离的更强猜想。

### 2.3 实际主项与参数盒上界不能混淆

比值判据先使用实际的 `|hJ| <= r`，再除以 `1-r`。一个为方便计算而放大的盒上界 `C` 不一定仍小于 `r`。正文在 (3.9) 前后明确作此区分，附录按实际来源实施估计；没有从任意 `C` 推出该不等式。

### 2.4 中心化插值需要无奇点版本

`D(t)=1-aμt` 可能为零。Lemma 3.2 同时给出含 `1/|D|` 的一阶插值估计与不含该分母的二阶估计；只有在整个积分小区间具有正的分母下界时才使用前者。`h=0` 的积分恒等式写为多项式恒等式，不通过除以 `h` 推出。

### 2.5 凸积分的三个限制

保留略去因子的改进使用每个积分区间上固定的下界 `δ_I`；不能先让该下界依赖积分变量，再沿用原凸性论证。每一个可用的凸上界分别积分，之后才对所得数值上界取最小值，未把凸函数的逐点最小值误认为凸函数。四次多项式对应 `m=3`，二阶插值中的平方根幂不满足所需凸性，因此该次数不使用相应中心化积分判据。

### 2.6 同一证书覆盖多个次数时，幂的方向必须分情况

位于 `[0,1]` 的底数用最小指数控制；保留略去因子的放大底数可能超过一，必须取两个端点幂的最大值。附录 A.2 明确写出此步骤。主乘积判据也先处理底数不大于一的情形，之后才使用关于次数的单调性。

### 2.7 四至七次的二次项不是绝对值误差

Lemma 6.5 保留中心化二次系数的实部，并控制 `μ` 的复相位。检查器对需要减去的正贡献使用向下取整，再从总上界中相减；不能对被减项向上取整。正文没有暗中把 `μ` 假设为实数。

### 2.8 逼近等号的区域不是通过取样排除的

Lemma 6.6 对 `3 <= m <= 12` 且 `r >= 99999/100000` 给出解析矛盾，保留严格正的 `1-r`。有限证书只有十个叶盒调用该引理，四次、五次各五个。它们并非“接近等号所以略去”的未验证盒。

### 2.9 其他退化情形

原零点距离方差 `C_0=0` 时单独说明协方差缺口为零，并退回合法乘积界；`V=0` 不使用含 `1/V` 的径向损失项；`v=0` 的插值估计不通过除以 `v` 证明；盒上不满足分母符号条件的判据不启用。所有这些分支均须保留，不能在压缩论文时删除。
